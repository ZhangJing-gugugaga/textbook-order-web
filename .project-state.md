# 项目状态：教材征订系统 · Web 端

## 一句话定义

面向高校 5 类角色（教材室/学院秘书/任课老师/学生/供货商）的教材征订 Web 端，把「教师填报 → 系统字段审查 → 超管内容复核 → 学生选购 → 多维度导出 → 通知确认闭环」搬到线上，替代纸质表格与群接龙。

## PRD 摘要

- **核心功能**：征订窗口引擎三态 + 教师填报两级审查 + 学生选购（覆盖更新）+ RBAC 动态路由与数据隔离 + 异步 Excel 导入 + 多维导出（含供货商分学院 sheet）+ 阻塞弹窗通知确认 + 异动两级审批 + 数据看板/通知管理。
- **排除项**：支付、教学班（重修/自修）、教材库存/出入库、AI 功能、小程序端（独立仓库）、后端实现（textbook-order-server）。
- **商业模式**：校内免费。
- **技术栈**：Vue 3.5 + Vite 6 + Element Plus 2.9 + Pinia 2.3 + Vue Router 4.5 + axios 1.7 + Vitest 3 + TypeScript 5.9；npm + package-lock.json 入库。

## 接口契约（联调基线 · 2026-09-22）

- **唯一契约源**：后端 `textbook-order-server/API.md` V1.0.4（95 端点）+ `GET /v3/api-docs`；前端已**全量按真实契约实现**（95/95 端点落地）。
- **联调环境**：后端以 **MySQL 8.0.29**（`E:\tools\mysql-local.bat start|stop`）+ `local` profile 运行在 `127.0.0.1:8080`；前端 dev/preview 由 Vite proxy 转发（同域，无需 CORS）。
- **联调测试**：`npm run test:api`（`scripts/api-contract-test.mjs`）—— 95 端点 × 三探针（未鉴权/越权/正常）+ 12 个契约语义场景，**真实 HTTP + 真实 MySQL**，自建 `[IT]` 夹具、可重复执行；报告落 `docs/API-INTEGRATION-REPORT.md`，结论落 `docs/CONTRACT-FIX-AND-INTEGRATION-REPORT.md`。
- **已移除 mock**：`mock/` 目录、`vite.mock.config.ts`、`vite-plugin-mock` 与 `mockjs` 依赖全部删除；接口基础地址统一为相对路径 `/api`，试运行/移交由 Nginx 反代。
- **时间格式不对称（实测，与 API.md §1.1 表述不符）**：JSON body 的 `LocalDateTime` 只认 ISO-8601（`yyyy-MM-ddTHH:mm:ss`）；query 参数只认空格格式（`yyyy-MM-dd HH:mm:ss`）。前端唯一转换点：`src/utils/format.ts` 的 `toWireDateTime` / `toPickerDateTime`。
