# 项目状态：教材征订系统 · Web 端

## 一句话定义

面向高校 5 类角色（教材室/学院秘书/任课老师/学生/供货商）的教材征订 Web 端，把「教师填报 → 系统字段审查 → 超管内容复核 → 学生选购 → 多维度导出 → 通知确认闭环」搬到线上，替代纸质表格与群接龙。

## PRD 摘要

- **核心功能**：征订窗口引擎三态 + 教师填报两级审查 + 学生选购（覆盖更新）+ RBAC 动态路由与数据隔离 + 异步 Excel 导入 + 多维导出（含供货商分学院 sheet）+ 阻塞弹窗通知确认 + 异动两级审批 + 数据看板/通知管理。
- **排除项**：支付、教学班（重修/自修）、教材库存/出入库、AI 功能、小程序端（独立仓库）、后端实现（textbook-order-server）。
- **商业模式**：校内免费。
- **技术栈**：Vue 3.5 + Vite 6 + Element Plus 2.9 + Pinia 2.3 + Vue Router 4.5 + axios 1.7 + Vitest 3 + TypeScript 5.9；npm + package-lock.json 入库。

## 接口契约（联调基线 · 2026-09-21）

- **唯一契约源**：后端 `textbook-order-server/API.md` V1.0.2（94 端点）+ `GET /v3/api-docs`；前端已**全量按真实契约实现**。
- **联调环境**：本机无 MySQL/Docker，后端以 **H2（MySQL 模式）文件库**承载（脚手架见 `E:\Desktop\work\TIAN\.it-harness`：`InitDb` 复用后端 `H2SchemaInitializer` 建表、`SeedRunner` 灌 `db/*.sql` 种子、`integration.mjs` 为 117 项端到端断言）。
- **已移除 mock**：`mock/` 目录、`vite.mock.config.ts`、`vite-plugin-mock` 与 `mockjs` 依赖全部删除；接口基础地址统一为相对路径 `/api`，dev/preview 由 Vite proxy 转发到 `VITE_PROXY_TARGET`，试运行/移交由 Nginx 反代。
